# VideoAgent 测试报告

测试日期为 2026-11-25（北京时间）。被测项目为本仓库中的 Go/C++ 实现。Go 与 C++ 由源码在隔离目录构建。原仓库未编辑。云端使用官方 DeepSeek `deepseek-flash`（thinking）、SiliconFlow `Qwen/Qwen3.8-27B` 做 VLM、`BAAI/bge-m3` 做文本向量、`Qwen/Qwen3-VL-Embedding-8B` 做视觉向量。原先试探的 2B 模型返回 HTTP 403。密钥仅通过运行进程环境传给对应服务。

## 本地验收与复现

| 检查 | 实测 |
|---|---|
| 构建与已有 Go 单测 | C++ 重建成功，Go 全包测试通过，`go test -race -count=3 ./...` 通过。随后执行的故障注入用例用于暴露现有失败。 |
| CFR 帧时序 | 25 fps 测试素材验证起点、569720 ms 事件起始、570280 ms 事件结束、最后一帧。负时间及达到或超过片长返回 InvalidArgument。采样数量 1、3、32 成功，0、33 拒绝。 |
| VFR 片尾 | 构造文件的帧 PTS 为 0、40、240、400 ms，容器报 320 ms。RPC 正确返回前半段的可见区间，在 399/400 ms 因容器片长边界拒绝。 |
| 采样引用 | 两次调用同一时间和目录，分别输出 320 和 640 像素宽。两次返回同一路径，第一次引用回读得到 640 宽。 |
| ASR 启动 | 原版 C++ 首次有效模型加载触发 `GGML_ASSERT(device)`，daemon 退出。仅在测试二进制显式注册本机 GGML CPU 后端后复测成功。 |
| ASR 真值样本 | 5 秒英文样本识别出重试次数，段时间为 0–7000 ms，结束越过视频片尾 2 秒。无音轨返回空结果，模型缺失返回 NotFound。完整教学视频为 zh、753 段，RPC 100.28 秒。 |
| OCR 与坐标 | 装入 `eng`、`chi_sim` 后，整帧和局部识别均可调用，局部词框正确回映射到原图。中文样本“中文测试 配置成功”正确。关键字段 `R0-17` 在同一控制帧的整帧和 ROI 两次均被读成 `RQ-17`。缺语言包返回 FailedPrecondition，反向框拒绝。 |
| gRPC 取消 | 12 次显式取消或 deadline 均返回相应状态，后续 health 成功。早期采样及 ASR 提取中断后，服务端退出分别最多约 8 ms 和 27 ms。串行复测覆盖 Whisper 模型加载与推理，客户端返回后最慢约 775 ms 才结束。单轮前后记录的句柄数与私有内存持平。 |
| SQLite 写入 | 两轮 1/2/4/8 Worker，每 Worker 25 次写入。单 Worker 两轮各成功 25/25，8 Worker 两轮仅成功 5/200、25/200。持有独立写锁时返回 SQLITE_BUSY，释放后可写。 |
| 证据落盘 | 写锁注入时 Harness 返回 evidence ID，随后按 run 查不到对应记录。视觉工具实际使用 `[]string` 引用，Harness 只按 `[]any` 读取。注入测试和真实数据库均复现空 refs。 |
| 同视频 ID | 顺序重复索引被拒绝。并行对同一 ID 索引 1070.56 秒与 5 秒两个文件，两个命令均返回 0，最终视频元数据为 5 秒，36 个分片仍延伸到 1070.56 秒。 |
| 预算与分页 | 65%/80%/90% 警告与强制收尾探针通过。总预算设为 1，Router 分出两个 Worker 并实际消耗 2 步。中文与 emoji 跨分页切割时出现替换字符。 |
| VLM 状态 | 四张控制帧直接调用指定 Qwen。小字、遮挡和错误因果诱导三例返回预期状态。无内容例返回空状态，客户端无错误。 |

## 真实教学视频与检索

- 1070.56 秒、1280×720、25 fps。在源码构建的测试 daemon 上，整轨抽取和 16 kHz 单声道重采样 818 ms，Whisper ASR RPC 共 100.28 秒。
- 带 Planner 的真实视频索引因高语音覆盖选择文本通道，问答仍通过原帧识别出课件题名。强制视觉索引的对照首次保存 36 条视觉向量记录，其中 28 条为空。服务端返回 HTTP 200，CLI 标为 ready_multimodal。整批 36 张的返回只有前 8 条有效。
- 测试版逐批 8 张并校验维数后，为 36 个分片全部生成了 4096 维向量。两种配置都答出了开头题名。复用真实 RPC ASR 结果的分批版本，在 1840 ms 返回 `real-teaching_frame_1840`。独立 FFmpeg 取帧和该帧的 SSIM 为 0.999985，画面显示“AI 写得比你读得快，code review 要怎么做？”。
- 可控九题的冻结索引有 6 条文本向量和 6 条有效视觉向量。独立检索探针的 Top-5 区间锚点命中从 8/13 提升到 10/13，纯视觉锚点从 5/10 到 7/10，全部所需锚点进入候选的题从 3/8 到 5/8。区间命中表示候选覆盖原视频时间，仍要检查中点帧或运行时视觉工具有没有实际看到事件。


本地计时补测 3 轮。36 个 30 秒分片每片 3 帧，共 108 帧，320×180。元数据读取 5.083–8.595 ms；采样不写 PNG 3.589–3.821 s；采样并写 PNG 3.784–4.046 s。均为本机 gRPC 墙钟时间。

九题视频另用相同 Whisper RPC 转写，耗时 33.98 s。6 句已知语音只转写出 3 句，并输出 37 条 `[BLANK_AUDIO]`。剔除这些标记后，33 个参考词有 16 个编辑错误，WER 为 48.48%。3 句匹配语音的起止误差中位数分别为 112 ms 和 154 ms。样本是长静默加短语音的压力工况。人工真值语音用于 A/B/C/D 主实验，避免 ASR 漏句把模型对照结果混在一起。

## 九题消融

九道可控题每组各运行一次，带真实云端模型。固定同一索引和人工转写；第 1–7 题在主实验中依次运行，第 8–9 题用独立数据库并行执行，VLM 的实际限流保留在结果中。Token 取 HTTP 响应的 usage，涵盖 Router、Worker 及子服务。下表的 DeepSeek Token 与 VLM Token 分列，P95 使用最近秩法。每组只有 9 次，P95 对应样本最大值。

评分按原子主张、证据和时间三项（50/30/20）。点用题目容差，区间用 tIoU；题目要求帧级取证时，明确 PTS、原帧可重取且内容匹配也可给分。无答案题的证据锚点设为不适用。整题通过要求关键主张齐全、核心证据能回放、关键时间命中。试点由单人逐题核对。附带错误与数据库原生追溯问题另记。逐题分项和例外记录在 manual-review.json。

- Q02 中 D 正确读到右上角的 R0-17，C 把数字零读成了字母 O，双通道单 Worker 也读对了目标编号。Q03 中 C、D 都漏掉 02:20 的状态转换。Q04 的文本检索加多 Worker 对照确认了非法端口及新值，但仍漏同一任务成功画面。Q06 中 D 找到 13:15 的第二次提示，把它当作首次，与 09:29.720 的真值相差 225.28 秒。
- D 相对 C 的 DeepSeek Token 合计为 1.45 倍；P50 为 1.15 倍。第 8–9 题并行负载、429 和单视频单次运行限制了时延和收益归因。三道补充对照共 6 次，本轮数据支持双通道提升候选召回，尚不足以确认多 Agent 的独立收益覆盖额外成本。
- 本轮 C/D 共 139 条被回答运行报告的 Evidence Store 记录缺少原始帧引用。部分答案仍可通过显式时间重新解码、或通过答案给出的 PNG 进行人工复核。自动证据链验收失败。

## 复测优先级

1. 先消除同 ID 并发建库时的跨版本混写、向量响应不全时的假就绪、Evidence Store 写失败与空引用。
2. 让现有 Windows 构建显式完成 Whisper 后端初始化，并测试纯静音标记、短音频片尾时间和词级接口。
3. 修复 Unicode 分页、采样文件名覆盖、全局预算下限和无内容 JSON 解析后，按相同题面和自然负载复测。随后用多个标注视频与重复运行检验 Router 的边际收益。

仍缺全量中文真值 CER、词级时间戳、长时资源浸泡和跨视频统计。没有用少量成功案例替代发布验收。
